Meet Riot Bot

Every mood means something.

Riot Bot's face isn't just cute. Each look maps to what your bots are actually doing.

Happy

Done. For real.

Every message becomes a durable job with a clear result: completed, failed, paused or interrupted. Every file edit gets an Undo.

Thinking

On it in the background.

Queue follow-ups, switch bots, close the window to the tray. Work keeps going, and two bots can run at once.

Focused

Clicking so you don't have to.

A real, visible browser with its own profile per bot. It reads whole pages, clicks, types, drags and switches tabs. Take over anytime.

Surprised

Asks before it acts.

New site, terminal command or outgoing email? You get a card. Remember & allow, this task only, or deny. Revoke anytime.

Sleeping

Zero idle model calls.

Riot Bot never calls a model while it's idle, opened or restarted. No mystery charges from a bot that was "just thinking."

Cheeky

Remembers your logins. Never sees them.

Passwords go into the Windows credential store. The model only ever gets an ID, and Riot Bot fills the password itself on the exact saved site.

Safety

Permissions live in code. Not in prompts.

Most AI agents are one sneaky web page away from doing something dumb. Riot Bot checks every file, terminal, browser, Gmail and spending decision in the app itself.

Web pages, emails, tool output, even the model's own replies can't approve an action, raise a budget, or unlock another bot's stuff.

  • Files stay in each bot's folder
  • You approve each terminal command
  • Every email send is previewed
  • Spending caps hold, even mid-task

Features

Built to actually get stuff done.

A crew, kept apart

Each bot gets its own memory, skills, folder, browser profile, schedules and saved logins.

Local-first

Chats, memories and files live on your PC. No account, no server, no sync, no telemetry.

Real browser control

Chromium, Chrome or Edge, visible on screen. Hand over the wheel for sign-ins, MFA or a CAPTCHA.

Gmail, reviewed

Your mailbox, your own Google app. Every send shows every recipient and the full message first.

Schedules

Reminders pop up without an AI call. Recurring tasks run with the bot's usual approvals and budget.

Keyless research

Web search and page reading work out of the box. No API key, no sign-up.

Files with undo

Each bot works in its own folder, with checks against sneaky links. Every edit can be undone.

Limits that hold

Call, time and dollar caps. Riot Bot never quietly switches your model, account or billing.

Use an API key, your ChatGPT account, or a model running on your own PC. Riot Bot never picks or swaps a model for you.

FAQ

Real talk.

Is it actually free?

Yes. Riot Bot is MIT licensed. If you use a paid API, you pay your model provider directly. With a local model like Ollama or LM Studio, it costs nothing to run.

Does it phone home?

No. There's no Riot Bot account, server, sync or telemetry. Data only goes to services you choose to use: your model provider, the sites a bot visits, Google for Gmail, and the research service for web search.

Mac or Linux?

Windows comes first. Other platforms and an always-on server version are on the roadmap.

Is it safe to give it my accounts?

Permissions are enforced in app code and passwords stay in the Windows credential store. It's still an early preview, though, so read the known limitations in the README and start with low-stakes accounts.
